# The cafe's own menu photographs

These twelve images were extracted from the base64 data URIs that used to be
inlined in `public/index.html`. They came off the cafe's printed menu PDF, so
they are pictures of the cafe's actual food -- more authentic than any stock
photo, but only ~640px wide, which looked visibly pixelated next to sharper
imagery once the sections were shown side by side.

They are kept here so nothing the cafe owns is lost. If the owner later
supplies high-resolution versions of these same dishes, they are the better
choice: crop 3:1, save as `<section>.webp` + `<section>.jpg` into
`public/img/`, and they will replace the stock photo with no code change.
